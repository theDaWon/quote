# 견적문의 페이지 만들기 — 따라 하기 안내서

> 천천히, 한 칸씩 따라 하면 됩니다.
> ☐ 네모 칸은 다 했으면 마음속으로 ✔ 표시하고 다음으로 넘어가세요.
> 사이트 화면의 버튼 이름은 영어이거나, 이 안내와 조금 다를 수 있어요. 비슷한 이름을 찾으면 됩니다.

---

## 시작하기 전에: 큰 그림

우리 페이지는 **4명의 친구**가 함께 일해요.

| 친구 | 하는 일 | 비유 |
|---|---|---|
| **GitHub** | 손님이 보는 견적 페이지를 보여줘요 | 가게 **진열장** |
| **Cloudflare R2** | 손님이 올린 파일을 보관해요 | 가게 **창고** |
| **Cloudflare Worker** | 손님이 진짜 사람인지, 파일이 괜찮은지 검사하고 창고에 넣어요 | 가게 **문지기** |
| **Google Apps Script** | 회사와 손님에게 메일을 보내요 | **우체부** |

그리고 **Turnstile**은 문지기가 "로봇 아니에요" 확인할 때 쓰는 도구예요.

## 준비물

- ☐ 컴퓨터와 **크롬(Chrome)** 브라우저
- ☐ 회사 **구글 계정** (메일을 보낼 계정)
- ☐ **신용카드 1장** — Cloudflare 창고를 열 때 필요해요. 무료 용량(10GB) 안에서는 돈이 나가지 않아요.
- ☐ 내려받은 `dawon-quote.zip` 파일 → 마우스 오른쪽 버튼 → **압축 풀기**
- ☐ **메모장**을 하나 열어 두세요. 중간중간 받는 주소와 열쇠를 여기에 적어 둘 거예요.

메모장에 아래처럼 빈칸을 미리 적어 두면 편해요.

```
① 비밀열쇠 A (SIGNING_SECRET)    :
② 비밀열쇠 B (MAIL_HOOK_SECRET)  :
③ 내 GitHub 주소                 :
④ Turnstile 사이트 키            :
⑤ Turnstile 비밀 키              :
⑥ Apps Script 웹 앱 주소         :
⑦ Worker 주소                    :
```

> 🔒 **약속:** ①②⑤번은 비밀이에요. 메모장에만 적고, 카톡·메일·블로그·GitHub에는 절대 올리지 마세요.

## 1단계. 비밀열쇠 2개 만들기 (5분)

비밀열쇠는 "우리끼리만 아는 암호"예요. 문지기와 우체부가 서로 진짜인지 확인할 때 써요.

1. ☐ 크롬을 열고 아무 페이지(예: 네이버)에 들어가요.
2. ☐ 키보드에서 **F12**를 눌러요. 오른쪽(또는 아래)에 복잡한 창이 열려요.
3. ☐ 그 창 위쪽에서 **Console**(콘솔)이라는 글자를 눌러요.
4. ☐ 맨 아래 깜빡이는 줄을 눌러 아래 글을 **그대로 복사해서 붙여넣고** Enter를 눌러요.

   ```js
   crypto.randomUUID().replaceAll('-','') + crypto.randomUUID().replaceAll('-','')
   ```

   > 붙여넣기가 안 되고 경고가 나오면 `allow pasting` 이라고 직접 치고 Enter, 그다음 다시 붙여넣으세요.

5. ☐ 따옴표 안의 긴 글자(숫자+영어 64글자)가 나와요. 따옴표는 빼고 복사해서 메모장 **①**에 붙여넣어요.
6. ☐ 4번을 **한 번 더** 해서 나온 새 글자를 메모장 **②**에 붙여넣어요. (①과 ②는 달라야 해요)
7. ☐ F12를 다시 눌러 창을 닫아요.

## 2단계. 진열장 만들기 — GitHub (15분)

### 2-1. 가입

1. ☐ https://github.com 에 들어가요.
2. ☐ 오른쪽 위 **Sign up** → 이메일, 비밀번호, 아이디를 넣고 가입해요.
   - 아이디는 주소에 들어가요. 예: 아이디가 `dawonsafety` 면 주소는 `dawonsafety.github.io`
3. ☐ 메일로 온 확인 숫자를 넣으면 가입 끝!

### 2-2. 저장소(폴더) 만들기

1. ☐ 오른쪽 위 **+** 버튼 → **New repository**
2. ☐ **Repository name** 칸에 `quote` 라고 써요.
3. ☐ **Public** 이 선택돼 있는지 봐요.
4. ☐ 맨 아래 초록 버튼 **Create repository** 를 눌러요.

### 2-3. 파일 올리기

1. ☐ 방금 만든 화면에서 **uploading an existing file** 이라는 파란 글씨를 눌러요.
2. ☐ 압축 푼 `dawon-quote` 폴더를 열어요. 그 안의 아래 것들을 **한꺼번에 마우스로 끌어다** 브라우저 화면에 떨어뜨려요.
   - `index.html`, `style.css`, `app.js`, `config.js`, `README.md`
   - `assets` 폴더 (로고가 들어 있어요)
   - `server` 폴더는 **올리지 않아도 돼요.** (다른 친구들에게 줄 거예요)
3. ☐ 다 올라가면 아래 초록 버튼 **Commit changes** 를 눌러요.

### 2-4. 진열장 문 열기 (GitHub Pages)

1. ☐ 저장소 위쪽 메뉴에서 **Settings**(톱니바퀴)를 눌러요.
2. ☐ 왼쪽 메뉴에서 **Pages** 를 눌러요.
3. ☐ **Branch** 에서 `None` 을 눌러 **main** 으로 바꾸고, 옆은 `/(root)` 그대로 두고 **Save**.
4. ☐ 1~2분 기다린 뒤 새로고침하면 위에 **Your site is live at ...** 주소가 보여요.
   예: `https://dawonsafety.github.io/quote/`
5. ☐ 메모장 **③**에 적어요. 단, **앞부분만** 적어요:
   `https://dawonsafety.github.io` ← 끝에 `/quote/` 도 `/` 도 없이!

> 지금 그 주소를 열어 보면 페이지는 보이지만 접수는 아직 안 돼요. 정상이에요. 나머지 친구들을 만들어야 해요.

## 3단계. 창고 만들기 — Cloudflare R2 (15분)

### 3-1. 가입

1. ☐ https://dash.cloudflare.com/sign-up 에 들어가 이메일·비밀번호로 가입하고, 메일 인증을 해요.

### 3-2. 창고(R2) 열기

1. ☐ 로그인한 화면 왼쪽 메뉴에서 **R2 Object Storage** (또는 Storage & Databases → R2)를 눌러요.
2. ☐ 요금제 구독 화면이 나오면 **무료(Free)** 를 확인하고 카드 정보를 넣어요.
3. ☐ **Create bucket** 버튼을 눌러요.
4. ☐ 이름 칸에 정확히 `dawon-quote-files` 라고 써요. 나머지는 그대로 두고 **Create bucket**.

> 🔒 창고 설정에 **Public access(공개 접근)** 가 보여도 **절대 켜지 마세요.** 켜면 아무나 파일을 볼 수 있어요.

### 3-3. 자동 청소 규칙 2개 넣기

1. ☐ 만든 창고(`dawon-quote-files`)를 눌러 들어가요 → 위쪽 **Settings** 탭.
2. ☐ 아래로 내려 **Object lifecycle rules** 에서 **Add rule** 을 눌러요.
3. ☐ **규칙 1**
   - 이름: `rate-clean`
   - 적용 범위(Prefix): `rate/`
   - **Delete objects** (객체 삭제) 켜기 → `2` 일
   - 저장
4. ☐ **규칙 2**
   - 이름: `upload-clean`
   - 적용 범위: **전체**(Prefix 비워 두기)
   - **Abort incomplete multipart uploads** (끝나지 않은 업로드 정리) 켜기 → `1` 일
   - (규칙 2에서는 Delete objects 를 **켜지 마세요**)
   - 저장

> ⚠ 파일이 들어 있는 `files/` 는 청소 규칙을 넣지 않아요. 파일 보관기간은 문지기(Worker)가 하나하나 따로 관리해요.

## 4단계. 로봇 검사 도구 만들기 — Turnstile (5분)

1. ☐ Cloudflare 왼쪽 메뉴에서 **Turnstile** 을 눌러요.
2. ☐ **Add widget** (또는 Add site) 버튼.
3. ☐ Widget name: `견적문의`
4. ☐ **Hostname** (도메인) 칸에 메모장 ③에서 `https://` 를 뺀 부분을 적어요.
   예: `dawonsafety.github.io`
5. ☐ Widget Mode: **Managed**
6. ☐ **Create** 를 누르면 키가 2개 나와요.
   - **Site Key** → 메모장 **④**
   - **Secret Key** → 메모장 **⑤** 🔒

## 5단계. 우체부 만들기 — Google Apps Script (15분)

> 회사 메일을 보낼 **구글 계정으로 로그인**한 상태에서 하세요.

### 5-1. 새 프로젝트에 코드 넣기

1. ☐ 크롬 주소창에 `script.new` 라고 치고 Enter. 새 프로젝트가 열려요.
2. ☐ 왼쪽 위 **제목 없는 프로젝트** 를 눌러 이름을 `다원안전 견적메일` 로 바꿔요.
3. ☐ 가운데 코드 칸에 있는 글을 **Ctrl+A** (전체 선택) → **Delete** 로 다 지워요.
4. ☐ 압축 푼 폴더의 `server` → `Code.gs` 를 **메모장으로 열어요** (오른쪽 버튼 → 연결 프로그램 → 메모장).
5. ☐ 메모장에서 **Ctrl+A** → **Ctrl+C**, Apps Script 코드 칸에 **Ctrl+V**.
6. ☐ 위쪽 💾 **저장** 버튼(또는 Ctrl+S).

### 5-2. 비밀열쇠 넣기

1. ☐ 왼쪽 맨 아래 ⚙ **프로젝트 설정** 을 눌러요.
2. ☐ 맨 아래 **스크립트 속성** → **스크립트 속성 추가**
   - 속성: `MAIL_HOOK_SECRET`
   - 값: 메모장 **②** 비밀열쇠 B
3. ☐ **스크립트 속성 저장**.

### 5-3. 메일 보내기 허락하기 (테스트 메일)

1. ☐ 왼쪽 **< >** (편집기) 로 돌아와요.
2. ☐ 위쪽 함수 선택 칸에서 `testMail` 을 고르고 ▶ **실행**.
3. ☐ **권한 검토** 창이 나와요 → 내 구글 계정 선택.
4. ☐ "Google에서 확인하지 않은 앱" 화면이 나오면 → 왼쪽 아래 **고급** → **(안전하지 않음)으로 이동** → **허용**.
   > 내가 직접 만든 코드라서 나오는 안내예요. 괜찮아요.
5. ☐ `dawon_park@naver.com` 에 **[테스트] 견적문의 메일 발송 확인** 메일이 왔는지 확인해요.

### 5-4. 우체부 출근시키기 (배포)

1. ☐ 오른쪽 위 파란 **배포** 버튼 → **새 배포**.
2. ☐ 유형 선택 ⚙ → **웹 앱**.
3. ☐ 설명: `견적메일`
   - **다음 사용자 인증 정보로 실행**: **나**
   - **액세스 권한이 있는 사용자**: **모든 사용자**
4. ☐ **배포** → 나오는 **웹 앱 URL** (`https://script.google.com/macros/s/.../exec`) 을 **복사** → 메모장 **⑥**.

> "모든 사용자"로 해도 괜찮아요. 비밀열쇠 B가 없으면 우체부가 아무 일도 하지 않아요.

## 6단계. 문지기 만들기 — Cloudflare Worker (15분)

### 6-1. 문지기 만들고 코드 넣기

1. ☐ Cloudflare 왼쪽 메뉴 **Workers & Pages** → **Create** (또는 Create application).
2. ☐ **Create Worker** (Start with Hello World) 선택.
3. ☐ 이름에 `dawon-quote` 라고 쓰고 **Deploy**.
4. ☐ 다음 화면에서 **Edit code** 를 눌러요.
5. ☐ 왼쪽 코드 칸을 **Ctrl+A** → **Delete** 로 지우고,
   압축 푼 폴더의 `server` → `worker.js` 를 메모장으로 열어 **Ctrl+A → Ctrl+C**, 코드 칸에 **Ctrl+V**.
6. ☐ 오른쪽 위 **Deploy** 를 눌러요.
7. ☐ 화면에 보이는 문지기 주소 `https://dawon-quote.○○○.workers.dev` 를 메모장 **⑦**에 적어요.

### 6-2. 문지기와 창고 연결하기

1. ☐ 문지기(`dawon-quote`) 화면 위쪽 **Settings** 탭.
2. ☐ **Bindings** → **Add** → **R2 bucket**
   - Variable name: `BUCKET` (대문자 그대로)
   - R2 bucket: `dawon-quote-files`
   - **Deploy** (또는 Save)

### 6-3. 문지기에게 주소·열쇠 알려주기

**Settings** → **Variables and Secrets** → **Add** 를 눌러 아래 5개를 하나씩 넣어요.
**Type**(종류)을 꼭 맞게 고르세요.

| ☐ | Type | Variable name (똑같이) | Value (값) |
|---|---|---|---|
| ☐ | **Text** | `ALLOWED_ORIGIN` | 메모장 ③ (예: `https://dawonsafety.github.io`) |
| ☐ | **Text** | `MAIL_HOOK_URL` | 메모장 ⑥ |
| ☐ | **Secret** 🔒 | `TURNSTILE_SECRET` | 메모장 ⑤ |
| ☐ | **Secret** 🔒 | `SIGNING_SECRET` | 메모장 ① |
| ☐ | **Secret** 🔒 | `MAIL_HOOK_SECRET` | 메모장 ② (5단계에 넣은 것과 **똑같은** 값) |

다 넣었으면 **Deploy**.

### 6-4. 매시간 청소 알람 맞추기

1. ☐ **Settings** → **Trigger Events** (또는 Triggers) → **Add** → **Cron Triggers**
2. ☐ 입력 칸에 `0 * * * *` (영, 띄고, 별 4개를 띄어서) 를 쓰고 저장.
   → 매시간 정각에 보관기간이 지난 파일을 지워요.

## 7단계. 진열장에 주소 적기 (5분)

1. ☐ GitHub의 `quote` 저장소로 가서 `config.js` 파일을 눌러요.
2. ☐ 오른쪽 위 ✏ **연필 버튼** (Edit this file).
3. ☐ 두 줄을 바꿔요. **따옴표 ' ' 는 지우지 말고** 안쪽 글자만 바꿔요.

   ```js
   WORKER_URL: '메모장 ⑦ 주소',
   TURNSTILE_SITEKEY: '메모장 ④ 사이트 키'
   ```

   예시:
   ```js
   WORKER_URL: 'https://dawon-quote.dawonsafety.workers.dev',
   TURNSTILE_SITEKEY: '0x4AAAAAAAxxxxxxxxxxxx'
   ```
4. ☐ 오른쪽 위 초록 **Commit changes...** → 다시 **Commit changes**.
5. ☐ 1~2분 기다려요.

1. ☐ 메모장 ③ 주소 + `/quote/` 를 열어요. (예: `https://dawonsafety.github.io/quote/`)

3. ☐ 보고서 2개 이상, 알게 된 경로, 내 연락처·**내 메일 주소**를 넣어요.
4. ☐ 작은 PDF 1개 + 큰 파일(수백 MB) 1개를 올려요.
5. ☐ 개인정보 동의 체크 → **"사람입니다" 확인 칸** 체크 → **견적 문의 접수**.
6. ☐ 파란 막대가 끝까지 차고 초록색 "접수되었습니다" 글이 나오나요?
7. ☐ **회사 메일**(`dawon_park@naver.com`)에 견적문의 메일이 왔나요?
   - ☐ 파일 이름을 누르면 파일이 받아지나요?
   - ☐ **보관기간 변경** 링크를 누르면 설정 화면이 열리나요?
8. ☐ **내 메일**에 "접수 확인" 메일이 왔나요?

모두 ✔ 이면 끝! 🎉

## 안 될 때 확인하기

| 이런 일이 생기면 | 이걸 확인하세요 |
|---|---|
| 로고가 안 보이고 "(주)다원안전" 글자만 나와요 | GitHub에 `assets` 폴더째로 `logo.png` 가 올라갔는지 |
| "자동 접수 방지 기능을 불러오지 못했습니다" | 4단계 Hostname 이 ③에서 `https://` 뺀 값과 똑같은지 |
| "자동 접수 방지 확인에 실패했습니다" | Worker의 `TURNSTILE_SECRET` 이 ⑤와 같은지 |
| "서버와 연결하지 못했습니다" | `config.js` 의 Worker 주소(⑦), Worker의 `ALLOWED_ORIGIN`(③, 끝에 `/` 없음) |
| "알림 메일 발송이 지연되고 있습니다" | `MAIL_HOOK_URL`(⑥), 양쪽 `MAIL_HOOK_SECRET`(②)이 똑같은지, 5-3 권한 허용을 했는지 |
| "서버 처리 중 오류" | Worker에 `BUCKET` 연결(6-2)과 `SIGNING_SECRET`(①)이 있는지 |

그래도 안 되면 그 화면을 **캡처**해서 물어보세요.

## 나중에 바꾸고 싶을 때

| 바꾸고 싶은 것 | 어디서 |
|---|---|
| 견적 메일을 받는 주소 | Apps Script `Code.gs` 맨 위 `RECIPIENT` → 저장 → **배포 → 배포 관리 → ✏ → 버전: 새 버전 → 배포** |
| 로고 | GitHub `assets/logo.png` 를 같은 이름의 새 파일로 다시 올리기 |
| 기본 보관일수(30일), 하루 접수 상한(40건) | Worker 코드 맨 위 `LIMITS` → Deploy |
| 파일 개수·용량 제한 | Worker `LIMITS` **와** GitHub `app.js` 위쪽 숫자를 **둘 다** |
| "알게 된 경로" 항목 | GitHub `index.html` **와** Worker `ALLOWED_SOURCES` 를 **둘 다** |

> 💡 Apps Script 코드를 고친 뒤에는 꼭 **새 버전으로 배포**해야 바뀐 내용이 적용돼요. 그냥 저장만 하면 예전 코드가 계속 일해요.

## (참고) 보안은 이렇게 지켜요

| 걱정 | 이렇게 막아요 |
|---|---|
| 로봇이 마구 접수 | Turnstile 로봇 검사, 숨김 칸, 같은 메일·IP는 1분에 1번, 하루 40건까지 |

| 이상한 파일 | 정해진 확장자만 받고, 다운로드할 때 브라우저에서 바로 열리지 않고 "저장"만 됨 |

- 비밀열쇠가 새어 나간 것 같으면 1단계로 새 열쇠를 만들어 바꿔 넣으세요. (열쇠 A를 바꾸면 예전 메일의 링크는 모두 열리지 않게 돼요.)
